GOOGLE ADS SIMULATOR PRO

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Click New campaign to use the interactive campaign wizard.

Features:
- Google Ads Simulator Pro — Google Ads-inspired responsive interface
- Campaign objective and campaign type selection
- Destination selection: Website, Google Business Profile, Phone Calls, App
- Bidding strategy and target CPA / ROAS fields
- Location, languages, networks, devices, schedule and dates
- Search keywords / negative keywords or Performance Max themes and assets
- Ad headlines, descriptions, URL, sitelinks, callouts and preview
- Daily or campaign-total budget
- Review screen and simulated campaign creation
- Dashboard with sample metrics and pause / enable / edit / delete actions
- Saves simulated campaigns in browser localStorage

Important:
This is an independent educational simulator, not Google's official product. It does not connect to Google Ads, use Google Ads APIs, publish advertisements, or charge money. Metrics for newly created campaigns start at zero; sample campaigns are provided for demonstration.
